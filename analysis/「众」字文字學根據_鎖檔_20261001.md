# 「众」字文字學根據 — 鎖檔（2026-10-01）

> **性質**：鎖檔（定案存檔）。本文件所載字源、版本、批語證據經網版原文核對，一經鎖入不再回退。
> **適用判詞**：王熙鳳判詞「一徔二令三人木」／香菱判詞「自徔兩地生孤木」——凡「三人」「徔」處，一律以本檔字學根據為準。

---

## 〇、本輪定案（一句話）

> **「三人」唔係三個「人」咁簡單——三個「人」摺合就係「众」（眾），《說文》有據、清代已成立；判詞寫「三人」唔寫「眾」，就係要讀者自己摺合睇出「众」——九子都收喺一個「众」字入面，眾兄弟傻咗＝九子奪嫡。**

```
三人（三个「人」）──摺合──→ 众（眾兄弟，《說文》有據）
木（呆傻）
→ 眾兄弟傻咗——九子奪嫡
```

## 一、「众」字古已有之（唔係現代簡化字拆古人）

| 字書／出處 | 原文 | 要點 |
|---|---|---|
| 《說文·乑部》 | 「**乑，眾立也。从三人**」 | 三人之形即「眾立」，摺合為「众／乑」——本字在古 |
| 《篇海類編》 | 「魚琴切，音吟。**衆立也**。與乑異。**俗書爲衆字**」 | 「众」為「眾」之俗書，清代字典收錄 |
| 《康熙字典·補遺·子集·人字部》 | 「【篇海類編】魚琴切，音吟。衆立也。與乑異。俗書爲衆字。非。」 | **康熙字典有收「众」字條**——清代已成立 |
| 《國語·周語》 | 「**人三為眾**」 | 經典書證：三人＝眾 |
| 《易·說卦》 | 「坤為眾」 | 眾為多數之象 |
| 漢典字形分析 | 「会意；**从三人**」；「三」表示眾多 | 眾字本義＝三人成眾 |

**結論**：甲骨文已有「眾」形（日下三人）；「众」即三人會意，《說文》「众，眾立也，从三人」——「三人＝众」係古已有之嘅摺合字，唔係以現代簡化字反拆古人。

## 二、作者寫「三人」唔寫「眾」——判詞刻意摺合

**核對方法**：同回（第五回）之內，「眾」字照用五處，判詞偏偏寫「三人」：

| 位置 | 原文 | 用字 |
|---|---|---|
| 夢中歌 | 「寄言**眾**兒女，何必覓閒愁」 | 眾 |
| 秦氏房 | 「於是**眾**奶母伏侍寶玉臥好」 | 眾 |
| 警幻 | 「向**眾**姊妹道」 | 眾 |
| 警幻 | 「因又請問**眾**仙姑姓名」 | 眾 |
| 結尾 | 「嚇得襲人輩**眾**丫鬟忙上來摟住」 | 眾 |
| **判詞** | 「一徔二令**三人**木」 | **三人（刻意）** |

**邏輯**：作者明明識寫「眾」（同回五處），判詞卻寫「三人」——即係「三人」係一個要讀者自己摺合嘅謎面，摺合後就係「众」。繁體「眾」含「目」，寫「眾」就冇得摺；寫「三人」先可以摺合出「众」。「三」表多數——九子都收喺一個「众」字入面。

## 三、「木」＝呆傻——小說內證（第65回）

> 「二姑娘的渾名是『**二木頭**』，**戳一針也不知噯喲一聲**。」（興兒語，第65回）

「木」喺紅樓內部語言正係**呆傻／木訥**義——迎春綽號「二木頭」，戳針都唔嗌痛。「三人木」＝「眾兄弟傻咗」嘅「木」，就係呢個「呆傻」義，唔係「休棄」之「休」。

## 五、「徔」與「從」係兩個唔同嘅字（本輪更正）

### 字形結構對比

| 字 | 結構 | 筆畫 | 康熙字典 | 《說文》 |
|---|---|---|---|---|
| **徔**（U+5F94） | **彳 ＋ 从**（兩個「人」） | 9 | **未收作字頭** | 未收作字頭 |
| **從**（U+5F9E） | **彳 ＋ 辶（辵）＋ 从** | 11 | 【寅集下·彳字部】 | 「隨行也。从辵从，从亦聲」 |

**關鍵**：徔 冇「辶」（辵部行走義），從 帶「辶」。兩個字結構根本唔同——**唔可以當同一個字理解**。

### 版本差異（原文核對）

| 版本 | 判詞寫法 |
|---|---|
| **甲戌本** | 「一**徔**二令三人木」 |
| **庚辰本** | 「一**從**二令三人木」 |
| 通識本／排印本 | 統一作「一從」——**抹走徔字** |

（來源：知乎〈王熙鳳的判詞究竟是「一从二令三人木」，還是「一徔（從）二令三人木」〉；甲戌本為最古抄本，其字最接近作者原筆。）

### 徔嘅雙重本義——《爾雅》鐵證

| 層次 | 釋義 | 書證 | 判詞位置 |
|---|---|---|---|
| **跟從** | 就也／隨行 | 《廣韻》「就也」、《易·乾卦》「雲從龍，風從虎」、《禮·曲禮》「謀于長者，必操几杖以從之」 | **凡鳥偏従末世來**（正字位） |
| **自從** | 自也 | **《爾雅·釋詁》「徔，自也」** | **一徔二令三人木**（密碼位） |

### 徔 讀「知」（zi1，芝麻個芝）

- 「徔」係**入音字**——讀「知／芝」（zi1）先保住入音表達；讀「從」（cóng）就失去入音，意思大走樣。
- **一徔 ＝ 一知 ＝ 順治出家**（根源：棄江山令繼承體系失根基）。
- 通識本將「徔」直接讀成「從」，抹走咗：①《爾雅》「自也」本義；②入音字嘅語音密碼；③作者刻意用「徔」而唔用「從」嘅意圖。

**一個字，兩層意思（跟從／自從），兩個讀音（cóng／知zi1）——通識本只讀一層。**

## 六、字學文獻原文照錄（網版核對出處）

1. 漢典「徔」字條：拼音 cóng，部首 彳，部外 3，總筆畫 9，左右結構；「康熙字典未收錄『徔』字頭，請參考『從』字」。
2. 漢典「從」字條：康熙字典【寅集下·彳字部】康熙筆畫 11；《說文》「隨行也。从辵从，从亦聲」；康熙字典引「說文 本作从」。
3. 漢典「众」字條：《康熙字典·補遺·子集·人字部》「【篇海類編】魚琴切，音吟。衆立也。與乑異。俗書爲衆字。非。」；《說文》未收「众」字頭，參考「眾」：「多也。从乑目，衆意」。
4. 《國語·周語》「人三為眾」；《易·說卦》「坤為眾」（漢典「众」詳細解釋書證）。
5. 維基文庫《紅樓夢》第五回全文：判詞原文「凡鳥偏從末世來，都知愛慕此生才。一從二令三人木，哭向金陵事更哀。」
6. 百度百科「一从二令三人木」條：戚序本批「拆字法」、甲戌本朱批「折字法」；「甲戌本……判詞的『從』字是繁體，而簡體的『从』字作為本字收於康熙字典」。
7. 知乎〈王熙鳳的判詞究竟是「一从二令三人木」，還是「一徔（從）二令三人木」？〉：甲戌本抄作「一徔二令三人木」；庚辰本抄作「一從二令三人木」。

## 七、同框架縫合

| 之前定案 | 本輪確認 |
|---|---|
| 一徔 ＝ 順治出家（根源） | 《爾雅》「徔，自也」＋ 徔讀知（zi1）＝ 一知順治出家 |
| 三人木 ＝ 眾兄弟傻（九子奪嫡） | 三人摺合「众」＋ 木＝呆傻（第65回「二木頭」內證） |
| 判詞係折字法（非拆字） | 甲戌本朱批「折字法」——「折」即對摺／摺合 |
| 通識本誤導 | 通識本讀「從」抹走「自也」本義＋入音密碼＋徔字刻意 |

**判詞全案**：

```
凡鳥偏従末世來 ＝ 鳳生孝莊末世（従＝跟從·正字位）
都知愛慕此生才 ＝ 人人愛慕太子位（才／財正反）
一徔二令三人木 ＝ 順治出家（徔＝知）→ 二廢 → 眾兄弟傻（三人＝众）
哭向金陵事更哀 ＝ 哭向祖宗
```
