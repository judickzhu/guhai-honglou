留言區 · 集思優化

本站解讀為提問者個人讀法——或顛覆通識本／紅學定論，非權威共識。歡迎各方讀者留言：提出更正、補充證據、指正斷章取義，集思優化，改進解讀正確性。

留言方式（GitHub Issues）

點此開一個 Issue 留言（建議先登入 GitHub 帳號；無需本站帳號）：

✍️ 開 Issue 留言

  • 為咗改進解讀正確性，留言請附依據：抄本原文（甲戌／庚辰／蒙府／程乙）／脂批原文／史料出處與行號——站規「核對須以全文脈絡為據，不以孤立截句作證」，避免斷章取義。
  • 指正範圍：任何回卡、判詞、十二支曲、字音字形解碼、成書與流傳。
  • 留言由站主審閱：合則入卡（標註來源），不合則存檔不採納——公開、可核對。
  • 已有回覆會集中喺 問答區 同步。

進階（可選）

若想頁內直接留言（唔使跳去 GitHub）：開啟倉庫 Discussions（Settings → Features → Discussions）後可接入 giscus；或安裝 utterances App（以 Issues 為評論）。兩者皆免費、無後端，需要時我可代為接入。
