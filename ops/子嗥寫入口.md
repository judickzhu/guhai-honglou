# 子嗥寫入口（2026-09-12）

openclaw 裡的子嗥可直接修改網站《紅樓夢》文字——改「資料源」JSON，推完即上線。

流程:
1. 讀: tools/content-source/honglou_*.json（素材）
2. 改: python3 編輯 JSON（UTF-8），改完驗證 `python3 -c "import json;json.load(open('檔案'))"`
3. 生成: `python3 tools/build_honglou_site.py`（冪等）
4. 推送: `bash tools/ops/gh_push.sh <工作副本> "改咗咩"`（GitHub REST API，不需 git）
5. 驗證: curl 線上頁面
