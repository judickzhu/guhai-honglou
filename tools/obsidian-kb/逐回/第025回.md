# 第25回　魘魔法叔嫂逢五鬼　通靈玉矇蔽遇雙真
幕:三 ｜ [[00-總覽|回總覽]]
## 解碼軌
- 【用户原话】 【紅玉夢見賈芸＝雍正×胤祥君臣組合過程】提問者直授（2026-10-05）：紅玉（<b>雍正</b>）情思纏綿·夢見賈芸（<b>胤祥</b>）拉佢——<b>賈芸拉紅玉＝胤祥拉雍正合作</b>；紅玉回身一跑（雍正迴避·試探）·被門檻絆倒（權力交接嘅障礙）·唬醒（現實焦慮）；批語「<b>有緣的，推不開；知心的，死不改</b>」＝<b>君臣緣分</b>（前世註定·「通靈神玉也遭塵敗」＝即使皇帝亦難逃命運）；「前生造定今生債」＝前世註定嘅君臣關係。
- 【用户原话】 【寶玉留心紅玉＝胤礽找雍正搭檔東山再起之初心；襲人此場景＝大阿哥】提問者直授（2026-10-05）：寶玉（<b>胤礽</b>）留心紅玉（<b>雍正</b>）——「若要直點名喚他來使用」＝想拉雍正入局；「<b>怕襲人等寒心</b>」＝<b>怕大阿哥（胤褆）不滿</b>——<b>襲人此場景＝大阿哥</b>（場景決定分身·非後來的雍正）；「不知紅玉是何等行為」＝未知雍正底細（若好＝真心幫手；若不好＝反骨難退）；「獨不見昨兒那一個」＝特別留意雍正——<b>找雍正搭檔東山再起之初心</b>（太子黨內部矛盾：胤礽想擴充勢力，大阿哥已不願有人爭）。
- 【用户原话】 【馬道婆＝榮妃馬佳氏；趙姨娘＝宜妃郭絡羅氏；賈環＝三阿哥胤祉——作者「混寫」】提問者直授（2026-10-05）：第25回「過了一日，就有寶玉<b>寄名的乾娘馬道婆</b>，進榮國府來請安」——<b>馬道婆＝榮妃馬佳氏</b>（「寄名乾娘」＝榮妃<b>曾代為撫養皇太子胤礽</b>三年，故書中設為寶玉寄名乾娘——撫養關係即密碼本體）；<b>趙姨娘＝宜妃郭絡羅氏</b>（宜妃生皇九子<b>胤禟</b>——「老八黨」核心、雍正朝改名「塞思黑」圈禁而死，故趙姨娘與馬道婆合謀魘鎮）；<b>賈環＝三阿哥胤祉</b>。<b>「混寫」手法</b>：正史中<b>三阿哥胤祉係榮妃馬佳氏所生</b>，與宜妃無血緣；書中卻將賈環寫成趙姨娘（宜妃）所生——即<b>將三阿哥之生母（榮妃）與九阿哥之生母（宜妃），壓縮入同一場景、同一陰謀</b>；馬道婆（榮妃）＋趙姨娘（宜妃）聯手魘鎮寶玉（胤礽）＝<b>三阿哥胤祉與九阿哥胤禟兩陣營，喺九子奪嫡中都曾參與圍攻太子</b>——作者以「混寫」將兩個皇子之生母合成一組「共犯」。此即「身分之術」：同一場景可同時承載多個歷史人物之關係，唔需要一對一固定對應。<b>【史實待核】</b>榮妃撫養胤礽一事，本站未能獨立驗證來源（web search 未配置）——標⚠️待核，惟此為提問者體系之關鍵前提。
- 【用户原话】 【點燈＝榮妃試探康熙對胤礽之態度；賈母（此場景）＝康熙】提問者直授（2026-10-05）：馬道婆點燈一段——<b>賈母（此場景）＝康熙</b>、寶玉＝胤礽、點燈＝為胤礽祈福（或試探）。「<b>若是為父母尊親長上點，多舍些不妨；像老祖宗如今為寶玉，若舍多了倒不好</b>」＝<b>榮妃試探康熙對胤礽之態度</b>：若康熙願多舍（多花錢祈福）＝仍愛胤礽；若話唔好＝已放棄；馬道婆要睇嘅就係康熙呢個「掂量」之結果。<b>脂批三路標（循序齊全·甲戌側批）</b>：①「<b>賊婆先用大鋪排試之</b>」（喺南安郡王府太妃四十八觔油等大鋪排之後）→②「<b>點頭思忖是量事之大小，非吝嗇也</b>」（甲眉·賈母聽後點頭思忖處；另有異文作「嗇非吝也」）→③「<b>賊婆是自太君思忖上來，後用如此數語收之，使太君必心悅誠服願行。賊婆，賊婆，費我作者許多心機摹寫也</b>」（「若舍多了倒不好」句旁）——<b>先大鋪排試之→太君思忖→數語收之</b>，即馬道婆（榮妃）睇準賈母（康熙）思忖、用數語收服之循序手法。<b>甲眉批補政治帳</b>：「<b>爲一小兒，如何服衆，太君細心若是</b>」——批者親口點出朝局壓力：康熙為一個小兒（胤礽）耗費如此，如何服眾。<b>榮妃雙重立場（兩難）</b>：曾撫養胤礽（有感情）／親生仔胤祉（有奪嫡之心）——故表面祈福、實則試探。<b>【版本異文並列】</b>「賊<b>盜</b>婆」（源檔）／「賊<b>道</b>婆」（公網）；「<b>廢</b>我作者許多心機」（源檔）／「<b>費</b>我作者許多心機」（公網）；「量事之大小，非吝<b>嗇</b>也」（源檔）／「嗇非吝也」（公網）——甲戌側批傳抄歧異，並列存參。
