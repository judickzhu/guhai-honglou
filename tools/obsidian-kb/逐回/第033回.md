# 第33回　手足耽耽小動脣舌　不肖種種大承笞撻
幕:三 ｜ [[00-總覽|回總覽]]
## 解碼軌
- 【用户原话】 【忠順王府索琪官＝胤礽索回胤祥（「忠順」＝無背叛之心）】提問者✅更正（2026-10-17）：第33回忠順王府長史官索琪官一段——<b>忠順王＝胤礽</b>（<b>「忠順」二字點明：佢一直沒有背叛之心</b>）、<b>琪官（蔣玉菡）＝胤祥</b>；<b>⚠️更正：忠順王非康熙</b>；原文：「尊府不比別家，可以擅入索取，因此啟明王爺。王爺亦云：『若是別的戲子呢，一百個也罷了；只是這琪官隨機應答，謹慎老誠，甚合我老人家的心，竟斷斷少不得此人。』故此求老大人轉諭令郎，請將琪官放回」——<b>胤礽看重胤祥</b>（「啟明王爺」）→「<b>隨機應答，謹慎老誠</b>」＝胤祥能幹忠誠→「<b>甚合我老人家的心</b>」＝胤礽喜愛胤祥→「斷斷少不得此人」＝胤礽不肯放手→「求老大人轉諭令郎，請將琪官放回」＝<b>康熙叫胤礽放返胤祥</b>；<b>琪官「三五日不見回去」「近日和銜玉的那位令郎相與甚厚」「在東郊離城二十里置辦房舍」</b>＝<b>胤祥離開康熙身邊·同胤礽親近·暗中建立自己嘅勢力</b>——即<b>胤祥加入太子黨</b>。<b>⚠️更正</b>：非「與金釧兒投井成一離一入之對稱」——<b>兩事同寫胤礽事件（太子出事）：胤祥（琪官）受牽連（被忠順王／康熙索回）</b>。<b>與金釧兒投井並讀（同寫胤礽事件之兩種牽連）</b>：<b>琪官（胤祥）＝受牽連</b>（被索回）；<b>金釧兒（雍正）＝無事</b>（脫身·未受波及）——<b>⚠️更正：非「一離一入」之對稱</b>。
- 【用户原话】 【襲人嫁蔣玉菡＝雍正與胤祥最終君臣組合（⚠️此情節在第120回·非本回）】提問者直授·2026-10-17：<b>襲人＝雍正</b>（龍衣人）、<b>蔣玉菡（琪官）＝胤祥</b>；<b>襲人嫁蔣玉菡＝雍正與胤祥君臣組合</b>（第120回：蔣玉菡念寶玉舊情·益加周旋·以松花綠汗巾相認）；完整權力鏈：<b>琪官（胤祥）在忠順王（胤礽）身邊 → 離開胤礽身邊·與「銜玉的那位令郎」親近 → 最終同襲人（雍正）結合＝君臣組合</b>；「嫁」＝結合・臣服；與既有「茜香羅繫於襲人腰中＝胤祥輔助雍正」互證——<b>此即全書對雍正胤祥關係之終極交代</b>。<b>⚠️歸屬更正</b>：襲人嫁蔣玉菡係<b>後四十回（第120回）</b>之內容，此條原誤置第33回；本條保留為與「忠順王府索琪官」之連讀附註，正式落卡見第120回。
