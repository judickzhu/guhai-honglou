# 第110回　史太君壽終歸地府　王鳳姐力詘失人心

## 解碼軌
- 【用户原话】 【賈母壽終「享年八十三歲」＝時間刻度（順治刻度83＝1721·康熙六十年）·鳳姐力詘＝康熙晚年困局】提問者直授（2026-10-17）：第110回回目「<b>史太君壽終歸地府　王鳳姐力詘失人心</b>」——原文「聽見賈母喉間略一響動，臉變笑容，竟是去了，<b>享年八十三歲</b>。眾婆子疾忙停床」；<b>此場景賈母＝順治、鳳姐＝康熙</b>。<b>【數字咬合（時間刻度）】</b>順治生於1638年：<b>刻度83 → 1638＋83＝1721＝康熙六十年</b>；該年<b>康熙虛歲68</b>（1654生），<b>隔年（康熙六十一年·1722）康熙駕崩</b>；另一刻度：<b>順治刻度75 → 1713＝康熙五十二年·康熙59歲</b>——<b>已在一廢（1708）二廢（1712）太子之後</b>，<b>儲位空懸·至死未立儲之十年膠着期開端</b>。<b>賈母（順治）壽終 → 鳳姐（康熙）力詘失人心 → 隔年康熙歸西</b>（回目下聯「力詘失人心」＝康熙晚年困局：九子奪嫡·財政混亂·心力交瘁）。<b>【⚠️邊界（提問者定調·2026-10-17）】</b>：<b>「83」係時間刻度，非順治實壽</b>——<b>正史記順治「崩于養心殿，年二十四」，且正史根本冇寫出家之事</b>（《清世祖實錄》僅「上崩于養心殿」，連死因亦未提）；<b>「順治出家」係清代四大疑案之一·出自野史傳說</b>（唯「拜玉林取法名行痴」有《玉林國師年譜》可據）；故本站<b>不主張正史「掩蓋」，而係正史「未寫」</b>（正史之沉默留出傳說空間）；<b>可鐵證者：1638＋83＝1721＝康熙六十年·康熙虛歲68·隔年駕崩</b>——此為數學·無可駁；<b>「順治活到83」則屬框架刻度</b>（公網無證實亦無反證）。<b>【⚠️已撤回之論據】</b>先前曾以「第39回賈母『比我大好幾歲』與第110回『83歲』相矛盾」證「83為刻度」——<b>此論據錯誤·已撤回</b>：原文劉姥姥「我今年七十五了」、賈母「比我大好幾歲呢」＝<b>劉姥姥大·賈母小</b>（賈母<75），係<b>正常語句·並無矛盾</b>；「83是刻度」之成立<b>只需數學換算</b>（1638＋83＝1721·康熙虛歲68·隔年駕崩），無須此偽證據（此為「先有結論再找證據」之誤·記以自警）。
