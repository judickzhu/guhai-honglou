# 入站同步流程（固化）

## 三方生態鏈
| 角色 | 職責 |
|---|---|
| DeepSeek 網頁版（老友） | 解碼產出 |
| openclaw / ego-browser | 讀寫網站、提取網頁版 |
| DSH agent | **入站+同步**（寫真源並推上網站） |

## 同步鐵律（缺一即漏）
1. 改真源：tools/build_honglou_site.py
2. 同步產物三區（缺一即「網站未見」）：
   - 解碼軌 chapters/NNN.html
   - **詩詞解讀**（詩＝詩解，唔可只入解碼軌）
   - **人物點評**（來源 honglou_char_review.json）
3. 改前先讀實際內容（唔可用生成器文本 match HTML → 靜默失敗）
4. PUT 後必驗 raw.githubusercontent.com（不受 Pages 快取影響）
5. Pages 快取滯後 1-2 分鐘屬正常

## 教訓
- 生成器被改壞（字符串未閉合）→ 產物永遠舊；改完必 ast 自檢
- 只入解碼軌漏詩詞區 → 提問者發現
- 用錯倉庫（deepseek-harness ≠ guhai-honglou）浪費大量排查
