# 《红楼梦》逐回解读框架（120 回 · 一回一卡）

> 本文是《红楼梦》解读网站的**内容规范**：120 回每回一张卡片、字段固定、双轨并行、全书定位。
> 数据底座：《红楼梦解读总纲_整理版.md》（提问者索隐解码体系）。框架与总纲兼容：总纲管"深度论据"，本框架管"逐回秩序"。

## 〇、站之根基（提问者亲授）：解白话 · 还原九子夺嫡真相

- **定位**：開放式解讀九子奪嫡這段歷史的網站——**只讀九子奪嫡還原的真相**，**只對書中的白話文字**。
- **方法**：**不索隱猜謎**；**對比版本差異**，以**甲戌本、庚辰本、蒙古王府本、程乙本**為底稿。
- **白话＝方言**：白話說白，就是留存在各地的方言裡；書中的很多**加密白話是廣府白話、廣府地區農民的土話可解**。
- **边界（诚实）**：其他方言能解多少，不敢妄斷。
- **红学家盲区**：胡適、王國維、周汝昌等紅學家對粵語白話一知半解，**沒有把書當歷史看**，所以解不出其中密碼。
- **與紅學最大的分野（提问者亲授）**：順治、康熙、胤礽、雍正四人，在寧榮兩府（家國同構坐標）裡**用不同的身分分身出現**——同一歷史人物隨府邸/場景切換成不同書中角色（一人多身）；紅學把分身當不同人、把家事當家事，本體系把分身合成同一人、把家事讀成國事——此即最大分野。
- **反向敘事（提问者亲授）**：作者用同一書中人物承載兩代歷史人物，隨場景切換身分——例：寶玉平時=胤礽身分、出家時=順治身分；賈政=康熙貫穿兩種身分（康熙是順治之子、胤礽之父，兩種父子關係皆成立）。一人多身的機制即反向敘事。
- **反寫實例（提问者亲授）**：賈珠十四歲進學=康熙14歲開始親政；賈珠20歲前娶妻生子一病死了=反寫交代胤礽母親病故；賈蘭=胤礽身分之一（用李紈=康熙身分養育）；「留女去男」也是作者的反寫交代。**書中是借冷子興之口交代清楚**（第二回「冷子興演說榮國府」＝分身體系與寧榮兩府結構的總交代）。
- **落位**：以「一回一卡、雙軌並行、九幕定位」為秩序，把《紅樓夢解讀總綱》的白話解讀體系，逐回落進固定框架。

## 一、四条秩序规则（保证"不乱"）

1. **一回一卡**：每回只允许一张卡片，字段顺序固定，不增删顶层字段；新发现写进对应字段，不另起炉灶。
2. **双轨并行**：每张卡片分「文学轨」与「解码轨」。文学轨=通识可读的情节与结构；解码轨=提问者体系的对标与字音字形考据。两轨分列，**不许混写**。
3. **全书定位**：每回必须标注所属「幕」（全书九段分期），任何单回解读都不能脱离总坐标。
4. **诚实边界**：解码轨一律标注来源——【提问者原话】或【AI 扩展·待核】；总纲未覆盖的回目，文学轨照常填写，解码轨明写「总纲未及，待解码」，不硬编。

**原稿层系判读（附于⑥存疑与版本）**：
- 雪芹舊有一書＝順治舊書（《風月寶鑑》），胤礽修改、胤祥（棠村）作序（总纲 L43571）。
- 「一芹一脂」＝胤礽（芹）＋胤祥（脂），寫書人與批書人，核心當事人；《石頭記》手抄本＝一芹一脂構成的加密整體（总纲 L2149/L28057）。
- 邊界：不考据旧本执笔者身份；舊書內容指向可引用。

**關係交代＝三生萬物·立體交錯（提问者亲授）**：身分不由單一線決定，而由多重線立體交錯決定——①世系代際線（順治→康熙→胤礽）②兩府矛盾線（胤褆 vs 胤礽，兄弟；康熙是她們的父親）③父子線（康熙 vs 胤礽／順治）④場所切換（賈政在家＝康熙、出外為官＝雍正）。讀者須按當下所處的「線」判斷身分；平面一對一必讀錯史事。

**家國同構（提问者亲授）**：寧府是大家（國/皇權），榮府是小家（家/家族），說家事即說國事——府邸即政治坐標。寧國府世系＝清帝世系：賈演→賈代化→賈敬→賈珍→賈蓉 ＝ 努爾哈赤→皇太極→順治→康熙→胤礽（第 5 代賈蓉＝胤礽太子地位）。
- 判定「後人修補」→ 標注【用户判断：後人修補，非原稿層】，不當原稿解讀，不混寫。
